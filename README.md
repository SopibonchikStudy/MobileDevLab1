# Bookline

Android-приложение первой лабораторной работы: локальная библиотека с четырьмя
Activity, каталогом из 12 книг, регистрацией и входом, настройками и резервной
копией.

## Запуск

Откройте корневой каталог в Android Studio, дождитесь синхронизации Gradle и
запустите конфигурацию `app`. Минимальная версия — Android 7.0 (API 24).

Проверки из спецификации:

```bash
./gradlew test
./gradlew assembleDebug
```

## Реализовано

- `StartActivity`, `RegistrationActivity`, `ContentActivity`,
  `SettingsActivity`; только стартовый экран является LAUNCHER.
- Jetpack Compose и Material 3, светлая/тёмная/системная тема и масштаб
  шрифта. Настройки сохраняются в `SharedPreferences`.
- Локальная регистрация и вход. Пароль хранится как HMAC-SHA256-хеш с
  уникальной солью; открытый пароль, хеш и соль не передаются между Activity и
  не пишутся в Logcat.
- Каталог из 12 книг с названием, автором, жанром, годом, рейтингом,
  доступностью и локальной обложкой-заглушкой.
- JSON-кэш каталога и `content_backup.json` версии 1 во внутреннем хранилище.
  Создание, проверка, восстановление и удаление копии выполняются в
  корутинах на `Dispatchers.IO`.
- Четыре ViewModel с `StateFlow`, одноразовые события и слои `domain`, `data`,
  `storage`, `ui`, `viewmodel`. Репозиторий каталога можно заменить реализацией
  REST без изменения Compose-экранов.
- Навигация через Activity Result: регистрация возвращает логин, настройки —
  логин и признак изменения профиля. Пароль через `Intent` не передаётся.
- Журналирование жизненного цикла всех Activity тегом `Lab1Lifecycle` в
  формате `ИмяActivity: метод`.

## Сценарий проверки копии

1. Войти в каталог и открыть настройки.
2. Создать резервную копию и подтвердить действие.
3. Нажать «Очистить каталог» и вернуться к данным: появится пустое состояние.
4. Из пустого состояния восстановить копию; каталог из 12 книг вернётся.
5. В настройках удалить копию; кнопки восстановления и удаления станут
   недоступны.

Логи для отчёта снимаются командой:

```bash
adb logcat -s Lab1Lifecycle
```

Первый сценарий: открыть `StartActivity`, опустить шторку уведомлений и
вернуться в приложение. Второй: пройти регистрацию, вернуться на старт, войти,
открыть настройки, вернуться в каталог и выйти. Для экрана данных выход
подтверждается диалогом; системная кнопка «Назад» в настройках сразу возвращает
каталог.

## Тесты

Unit-тесты проверяют границы валидации, количество и уникальность книг, состав
статусов доступности, диапазоны рейтинга и года. Compose UI-тесты требуют
Android-устройства или эмулятора и в текущей конфигурации не добавлены.
